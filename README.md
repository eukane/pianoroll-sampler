# 피아노롤 + 악기 교체 렌더러

노트를 마디 단위로 찍고, **같은 노트를 색소폰·가야금 등 어떤 악기로든 바꿔서**
들어보고, WAV / MIDI 로 뽑는 로컬 웹앱.

서버도 로그인도 없다. 브라우저 안에서 전부 돈다. 주 사용 환경은 **휴대폰**이라
터치를 1순위로 만들었다.

## 어디서 어떻게 여는가

이 앱은 **백엔드가 없는 정적 파일**이다. 한 번 올려 두면 그 뒤로는 주소만
열면 된다 — 컴퓨터도 서버도 필요 없다. 패드·폰에서 쓰는 게 목적이라 이게 기본
경로다.

| 방법 | 컴퓨터가 필요한가 | 인터넷 |
| --- | --- | --- |
| **올려 두고 주소 열기** (GitHub Pages) | 처음 한 번만 | 필요 |
| 컴퓨터가 서버, 폰이 화면 (`dev:https`) | 켜 둬야 함 | 같은 와이파이 |
| 폰·패드 안에서 직접 (Termux, 안드로이드) | 필요 없음 | 설치할 때만 |

### 올려 두기 (GitHub Pages)

`main` 에 푸시하면 `.github/workflows/deploy.yml` 이 알아서 배포한다.
처음 한 번만 저장소 설정에서 켜 주면 된다.

1. **Settings → General → 맨 아래 Change visibility → Public**
   (Pages 가 무료인 조건이다)
2. **Settings → Pages → Source → GitHub Actions**

그러면 `https://<계정>.github.io/pianoroll-sampler/` 에서 열린다.
크롬에서 **홈 화면에 추가** 해 두면 앱처럼 뜬다.

올리기 전에 **빌드된 결과물이 실제로 도는지** 확인할 수 있다.

```bash
npm run build && npm run built-check
```

개발 서버에서 되는 것과 올려 둔 파일이 도는 것은 다른 얘기다. 하위 경로
서빙·워크렛 파일 위치·개발용 창구가 빌드에 섞였는지까지 화면만 보고 확인한다.

## 컴퓨터에서 돌리기

```bash
npm install
npm run dev          # 이 컴퓨터에서 볼 때
npm run dev:https    # 폰에서 접속할 때  ← 폰은 반드시 이쪽
```

**폰에서 볼 때는 `npm run dev:https` 를 써야 한다.** 사운드폰트 재생에 쓰는
AudioWorklet 이 보안 컨텍스트(https 나 localhost)에서만 동작하는데,
`http://192.168.0.5:5173` 은 보안 컨텍스트가 아니다. 그냥 `npm run dev` 로
띄우고 폰에서 붙으면 `.sf2` 가 열리지 않는다 (앱이 접속하자마자 알려 준다).

인증서는 그 자리에서 만든 것이라 브라우저가 "안전하지 않다" 고 경고한다.
내 컴퓨터에 내가 붙는 것이니 **고급 → 계속** 을 누르면 된다.

**첫 화면을 한 번 탭해야 소리가 켜진다** — 폰 브라우저 규칙이라 우회할 수 없다.

```bash
npm run build      # 타입 검사 + 프로덕션 빌드
npm run smoke      # 브라우저 자동 점검 97가지 (dev 서버를 띄워 둔 상태에서)
npm run midi       # MIDI 왕복 점검 20가지 (브라우저 없이, 1초)
npm run names      # 샘플 파일명 읽기 점검 19가지 (브라우저 없이)
npm run audit      # 고치다 옆엣것을 깨뜨리지 않았는지 35가지 (브라우저 없이)
npm run clipboard  # 복사·붙여넣기 점검 15가지 (브라우저 없이)
npm run latency    # 이 기기에서 사운드폰트가 몇 ms 늦는지 실측 (통과/실패 아님)
```

`npm run smoke` 는 테스트용 SF2 를 직접 만들어 쓴다(`scripts/gen-fixture.mjs`).
1.2KB 짜리라 음원을 받지 않아도 프리셋 목록·검색·악기 교체 경로가 전부 돈다.

## 진행 상황

### 음 하나씩 조교하기 (꾸밈) ✅

- **이번에 된 것**: 피아노롤에서 **노트를 톡 치면** 그 음만 어떻게 연주할지
  고를 수 있다 — 떨림 · 끌어올림 · 흘러내림 · 꺾기. 같은 음높이를 찍어도
  하나는 밑에서 끌어올리고 하나는 끝에서 흘려 내릴 수 있다.
- **확인하는 법**: 예제 곡을 열면 멜로디에 손본 자리가 셋 있다 (첫 음 끌어올림,
  제일 높은 자리 꺾기, 구절 끝 흘러내림). 노트 오른쪽 끝의 `↗ ∧ ↘` 표시가
  그것이다. 톡 쳐서 바꿔 보면 고르는 즉시 들려준다.
- **믹서의 「기본 떨림」은 다른 것**: 그건 "이 악기는 긴 음을 으레 이렇게 분다"
  는 설정이고, **꾸밈을 정하지 않은 음에만** 걸린다. 전부 떨면 기교가 아니라
  버릇이다.
- **빠르기는 없다**: 흔드는 속도(8.1Hz)는 사운드폰트가 정한다. 재 봤더니 CC76
  으로 바꿀 수가 없어서, 임시 신스와 낱개 WAV 도 같은 속도에 맞췄다. 자세한
  실측은 [`DECISIONS.md`](DECISIONS.md).

### 예제 곡 ✅

- **이번에 된 것**: `💾 내보내기 → 🎵 예제 곡 불러오기` 로 8마디짜리 임시 곡이
  들어온다. 멜로디 · 반주 · 베이스 세 트랙.
- **확인하는 법**: 두 번째 트랙(반주) 이름을 눌러 악기를 바꿔 보면, **같은
  노트가 그대로 다른 악기로** 난다 — 이 앱의 요점이 그 한 번에 보인다.
- **어떻게 짰나**: D 장조 5음계만 써서 노트를 아무렇게나 옮겨도 안 부딪힌다.
  전부 1/8 격자에 떨어지고, 음원이 없어도(임시 신스만으로도) 곡으로 들린다.

### 맨 앞으로 · 누른 만큼 소리내기 ✅

- **이번에 된 것**: `⏮` 버튼(단축키 `Home`)으로 재생 위치를 맨 앞으로 되돌린다.
  왼쪽 건반은 **누르고 있는 동안** 울린다 — 위아래로 밀면 음이 따라온다.
- **확인하는 법**: 12마디쯤 스크롤해 두고 `⏮` 을 누르면 화면까지 같이 앞으로
  온다. 루프가 켜져 있으면 루프 시작으로 간다(재생도 거기서 시작하니까).
- **주의**: 뜯는 소리(가야금)는 붙잡지 않는다. 실제로 줄은 뜯은 만큼만 울리고
  손을 대고 있어도 길어지지 않는다 — 여운을 그대로 살려 둔다.

### 박자 맞추기 (M5 뒤 손질) ✅

- **이번에 된 것**: 사운드폰트 트랙만 **70.9ms 늦게** 울리던 것을 고쳤다.
  워크렛이 예약 시각을 자기 시계로 판정하는데 그 시계가 처음부터 어긋나 있었다.
- **확인하는 법**: 임시 신스 트랙과 사운드폰트 트랙에 같은 마디를 찍고 같이
  재생한다. `.sf2` 를 읽고 나면 상태 줄에 `· 박자 62ms 보정` 이 뜬다 —
  기기마다 다른 값이라 상수로 박지 않고 소리 없이 실측한다.
- **곁다리**: 건반을 눌렀을 때 사운드폰트만 굼뜨던 것도 같이 사라졌다.

### M5 — 다듬기 ✅

- **이번에 된 것**: 트랙별 음량·팬·음소거·솔로, 리버브(센드 방식), 실행 취소 /
  다시 실행, 최소한의 키보드 단축키.
- **확인하는 법**: `🎚️ 믹서` 에서 슬라이더를 움직이면 재생에도 내보낸 WAV 에도
  똑같이 반영된다. 편집 후 `↶` 로 되돌리기 (드래그 한 번 = 되돌리기 한 번).
- **단축키**: 스페이스(재생·정지) · Home(맨 앞으로) · Ctrl+Z / Ctrl+Shift+Z ·
  Esc(창 닫기).

### M4 — 커스텀 샘플 폴더 (가야금용) ✅

- **이번에 된 것**: 낱개 WAV 를 폴더째로 넣으면 파일명에서 음높이를 읽어 자동
  배치(`가야금_C4.wav` · `gayageum-60.wav` · `sax_A#3_mf.wav`), 못 알아들은
  파일은 수동으로 건반 지정, **없는 음은 가장 가까운 샘플을 피치 시프트로**
  채움, 세기 층(`_p`/`_mf`/`_f`) 인식, 릴리즈 꼬리.
- **확인하는 법**: `🎹 악기이름` → `＋ 폴더 넣기` 로 단음 WAV 들을 고른다.
  스무 개 남짓이면 두 옥타브가 연주된다.
- **아직 아닌 것**: 믹서·리버브·실행취소는 M5.

### M3 — 내보내기 / 가져오기 ✅

- **이번에 된 것**: WAV(전체 믹스, 44.1kHz·16bit) · **트랙별 WAV(스템)** ·
  MIDI(SMF 포맷 1) 내보내기, `.mid`·프로젝트 `.json` 가져오기.
- **확인하는 법**: `💾 내보내기` → 원하는 형식. 다른 DAW 에서 만든 `.mid` 를
  `📂 열기` 로 넣고 악기만 바꿔 다시 뽑는 왕복이 된다.
- **아직 아닌 것**: 국악기처럼 WAV 낱개로 오는 음원은 M4. 믹서·실행취소는 M5.

### M2 — 샘플러 + 악기 교체 ✅

- **이번에 된 것**: `.sf2`/`.sf3` 넣기(파일 선택·드래그), 프리셋 검색("sax" 치면
  색소폰만), 트랙별 악기 지정, **두 번 탭으로 악기 교체**(노트는 그대로),
  트랙 최대 16개 동시 재생, 트랙별 출력 분리.
- **확인하는 법**: `📂 음원` 으로 GM 사운드폰트(`.sf2`)를 넣고 → `🎹 악기이름`
  탭 → "sax" 검색 → 아무 색소폰이나 탭. 찍어 둔 멜로디가 그대로 색소폰으로 난다.
  트랙 줄의 `＋` 로 트랙을 늘리고 트랙마다 다른 악기를 걸 수 있다.
- **아직 아닌 것**: 내보내기는 M3. 국악기처럼 WAV 낱개로 오는 음원은 M4.

### M1 — 피아노롤 에디터 + 임시 신스 ✅

- **이번에 된 것**: 캔버스 피아노롤(탭=찍기, 드래그=옮기기, 오른쪽 끝=길이,
  길게=삭제, 두 손가락=가로 확대), 1/4·1/8·1/16 스냅, 재생/정지·재생 헤드·루프
  구간, 오실레이터 임시 소리, 폰 오디오 잠금 해제.
- **확인하는 법**: `npm run dev` → 폰으로 접속 → 화면 한 번 탭 → 격자를 눌러
  4마디쯤 멜로디를 찍고 `▶︎ 재생`. 위쪽 눈금을 드래그하면 루프 구간이 잡힌다.
- **아직 아닌 것**: 소리는 임시 오실레이터다. 진짜 악기(색소폰·가야금)는 M2·M4.
  내보내기는 M3.

## 음원 구하는 곳

음원은 저장소에 넣지 않는다(라이선스가 제각각이라 번들로 묶으면 안 된다).
직접 받아서 앱에 넣는 구조다.

- **일반 악기 (색소폰 포함)** — General MIDI 사운드폰트 하나면 128개 악기가 다
  들어 있다. `GeneralUser GS`, `FluidR3_GM`, `MuseScore_General` 등이 무료.
  색소폰은 GM 프로그램 번호 65~68 (소프라노/알토/테너/바리톤).
- **국악기 (가야금·해금·대금 등)** — 국립국악원 「국악기 디지털 음원」에서 단음
  음원을 받을 수 있다. <https://www.gugak.go.kr/digitaleum/front/monotone/list.do>
- 서울대 예술과학센터 국악 VSTi 프로젝트 — <http://www.catsnu.com/Project/GugakVSTi.aspx>

> 받은 음원마다 라이선스와 상업적 이용 조건이 다르다. 쓰기 전에 각 배포처의
> 조건을 확인할 것.

## 구조

```
src/
  model/     Note · Track · Project (노트는 악기 정보를 갖지 않는다)
             · ornament(음 하나에 붙는 꾸밈 — 시김새) · demoSong(예제 곡)
  audio/     engine(잠금해제) · scheduler(lookahead) · mixer(트랙별 배선)
             · instrument(인터페이스) · oscInstrument(음원 없을 때)
             · soundfont(SF2 샘플러) · folderSampler(낱개 WAV)
             · reverb(계산으로 만든 울림) · mixerState(뮤트·솔로 판단)
             · vibrato(떨림 — 왜 깊이만 있고 빠르기는 없는지)
             · expression(트랙 기본값 + 음의 꾸밈 = 이 음의 연주법)
             · registry(악기 교체가 일어나는 유일한 지점)
  ui/        pianoroll(캔버스 + 터치) · notePanel(음 하나 조교)
             · instrumentPanel(음원·프리셋·트랙)
             · exportPanel(내보내기·가져오기) · mixerPanel(음량·팬·울림) · theme
  history.ts 실행 취소 (스냅숏 방식)
  export/    midi(SMF 읽기·쓰기) · wav(16bit PCM) · render(오프라인 렌더)
             · projectFile(저장·불러오기)
  util/      music(음높이 변환)
```

설계 판단의 근거는 [`DECISIONS.md`](DECISIONS.md) 에 남긴다.
